🧠 1. APA ITU PROGRAMMING?

Programming atau pemrograman adalah proses membuat sekumpulan instruksi agar komputer melakukan sesuatu.

Contohnya sangat sederhana. Ketika kita memberikan perintah:

Nyalakan lampu.

Komputer tidak langsung memahami kalimat tersebut seperti manusia. Komputer membutuhkan instruksi dalam bentuk yang dapat diproses oleh sistemnya.

👤 MANUSIA
↓
💻 PROGRAM
↓
🤖 KOMPUTER
↓
⚙️ TINDAKAN

Jadi programmer sebenarnya adalah orang yang memberikan instruksi kepada komputer menggunakan bahasa yang dapat dipahami komputer.

🔢 2. MENGAPA KOMPUTER MENGGUNAKAN 0 DAN 1?

Ini bagian yang sangat penting.

Komputer pada dasarnya bekerja menggunakan sinyal elektronik. Sistem elektronik lebih mudah membedakan dua kondisi:

🔌
0
Tidak aktif
⚡
1
Aktif

Karena itu komputer menggunakan sistem yang disebut binary atau bilangan biner.

0 = OFF 1 = ON 10101001 11001010 00101101

Tetapi manusia tentu tidak nyaman jika harus menulis semua program menggunakan 0 dan 1.

Karena itulah manusia membuat bahasa pemrograman.

💻 3. BAHASA PEMROGRAMAN

🔘 5. BOOLEAN — BENAR ATAU SALAH

Boolean adalah tipe data yang hanya memiliki dua keadaan utama:

✅
TRUE
Benar / Aktif
❌
FALSE
Salah / Tidak aktif

Dalam robotik, Boolean sangat berguna untuk menyatakan kondisi sensor.

ada_garis = True ada_halangan = False

Artinya:

📡 Sensor
↓
Membaca kondisi

🔀 6. IF / ELSE — MEMBUAT KEPUTUSAN

Program tidak hanya melakukan perintah. Program juga dapat mengambil keputusan.

Contohnya:

if ada_garis: maju() else: berhenti()

Artinya:

ADA GARIS?

⬇️

YA → 🚗 MAJU

TIDAK → 🛑 BERHENTI

Inilah salah satu konsep terpenting dalam robotik: program membaca kondisi kemudian memilih tindakan.

🔁 7. LOOP — MENGULANG PERINTAH

Robot biasanya tidak hanya membaca sensor sekali. Robot harus membaca sensor berkali-kali selama bergerak.

while True: baca_sensor() tentukan_keputusan() gerakkan_motor()

Prosesnya seperti ini:

📡 BACA SENSOR → 🧠 PIKIR → ⚙️ GERAK → 📡 BACA LAGI → 🧠 PIKIR LAGI → ⚙️ GERAK LAGI → 🔁 ULANG

Inilah konsep LOOP.

Contohnya:

Sensor membaca garis. Jika ada garis: robot maju. Jika tidak ada garis: robot mencari garis.

Jadi robot sebenarnya bukan "berpikir" seperti manusia. Robot menjalankan aturan yang telah dibuat oleh programmer.

🏁 10. LINE FOLLOWER

Sekarang kita masuk ke salah satu contoh robotik yang sangat mudah dipahami: line follower.

Bayangkan robot memiliki dua sensor:

⬅️
Sensor Kiri
🤖
ROBOT
➡️
Sensor Kanan

Logika sederhananya:

Kiri = garis Kanan = tidak ada garis → Koreksi kiri Kiri = tidak ada garis Kanan = garis → Koreksi kanan Kiri = garis Kanan = garis → Maju Kiri = tidak ada garis Kanan = tidak ada garis → Cari garis

⚙️ 13. KECEPATAN VS KESTABILAN

Dalam lomba robotik, robot yang paling cepat belum tentu menjadi pemenang.

🐢
Terlalu lambat
Stabil tetapi lambat
💨
Terlalu cepat
Mudah keluar lintasan
🎯
Optimal
Cepat + stabil

Tujuan programmer robot bukan sekadar membuat robot bergerak, tetapi membuat robot bergerak dengan benar dan stabil.

🎛️ 14. MOTOR & PWM

Motor adalah bagian yang menghasilkan gerakan. Program dapat mengatur seberapa kuat atau cepat motor bekerja, tergantung sistem robot yang digunakan.

Salah satu konsep yang sering digunakan adalah PWM.

motor_kiri = 150 motor_kanan = 150

Jika kedua motor memiliki nilai yang sama, robot cenderung bergerak lurus.

motor_kiri = 100 motor_kanan = 180

Perbedaan kecepatan motor dapat membuat robot berbelok.

Coding → memengaruhi motor → motor memengaruhi gerakan.
